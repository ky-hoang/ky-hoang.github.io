## What I built

Co-developed with a partner: a Java exploration game with seeded procedural world generation. The same seed always produces the same world of randomized rooms and hallways.

## How it works

- **World generation:** rooms and hallways are placed at random from a seed
- **Navigation:** shortest paths across the generated map, using priority queues, hash maps and graph traversal
- **Play:** keyboard-driven exploration
- **Save and load:** a world can be saved and resumed in a later session

This was a class project, so the code is not public.
